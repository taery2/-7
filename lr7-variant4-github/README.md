## Задача Б
`dp[s]=1+min(dp[s-c])`, `dp[0]=0`. Восстановление выполняется по массиву предыдущих монет. Для S=200 минимум — **30 монет**, состав: **{1: 1, 3: 1, 7: 28}**. Результат проверяется перебором.

## Г4
При фиксированных номиналах 1,3,7:

| S | Медианное время, с |
|---:|---:|
| 100 | 2.2034e-05 |
| 200 | 4.1843e-05 |
| 400 | 9.0696e-05 |
| 800 | 0.000195174 |
| 1200 | 0.00029916 |
| 1600 | 0.000391188 |
| 2000 | 0.000608696 |
| 3000 | 0.000960686 |
| 4000 | 0.001212144 |
Внутренний цикл перебирает k=3 номинала для каждой суммы от 1 до S. Сложность `Θ(kS)`, при фиксированном k — линейная по S. Это псевдополиномиальный алгоритм.

## Вывод
Мемоизация и итеративное ДП устраняют повторные вычисления, присутствующие в наивной рекурсии. ДП для размена находит точное минимальное число монет и восстанавливает их состав.
